# 数据清洗管理系统 - 操作指引

## 系统概述

数据清洗管理系统（MDS）是一个主数据管理与数据质量控制平台，用于对接外部系统数据、进行数据校验、并推送到正式生产系统。

---

## 功能模块

系统包含以下7个数据模块：

| 模块 | 说明 | 主要字段 |
|------|------|----------|
| 物料 | 物料主数据管理 | 物料号、描述、规格、工厂等 |
| 工作中心 | 工作中心管理 | 编号、名称、产能、瓶颈标识等 |
| 产线版本 | 物料版本管理 | 物料号、版本号、批量范围等 |
| 工艺路线 | 工艺路线管理 | 物料号、工序号、工作中心、工时等 |
| BOM | 物料清单管理 | 父件号、子件号、用量等 |
| 模具 | 模具主数据管理 | 模具号、名称、类型、穴数等 |
| 机台模具 | 机台与模具关联 | 物料号、工作中心、模具号等 |

## 操作流程

### 标准数据清洗流程

```
导入数据 → 数据校验 → 处理异常 → 推送正式表
```

### 1. 导入数据

**方式一：Excel/CSV上传**
1. 点击模块页面上的 **「导入」** 按钮
2. 选择去重策略：
   - **覆盖重复**：更新已存在的记录（推荐）
   - **跳过重复**：保留原有记录
   - **拒绝重复**：遇到重复时报错
3. 拖拽或点击上传文件（支持 `.xlsx`, `.xls`, `.csv`）

**方式二：API接口调用**
- 调用 `POST /api/mds/{table_key}` 接口
- 适用于系统对接场景（ERP、MES、PLM等）

### 2. 数据校验

**单模块校验**
1. 点击 **「校验」** 按钮
2. 系统自动校验：必填字段、枚举值、外键引用、业务规则
3. 查看校验结果，处理异常数据

**全量校验**
1. 点击顶部导航栏的 **「校验全部」** 按钮
2. 系统按依赖顺序依次校验所有模块

### 3. 处理异常数据

**查看异常**
- 使用状态筛选器选择「校验失败」
- 点击记录查看详细错误信息

**处理方式**
- **编辑修正**：双击单元格直接编辑，保存后状态重置为「待处理」
- **批量编辑**：选中多条记录，点击批量编辑
- **删除无效数据**：选中后删除

### 4. 推送正式表

**单模块推送**
1. 确认校验通过后，点击 **「推送」** 按钮
2. 系统将数据同步到正式生产表

**全量推送**
1. 点击顶部导航栏的 **「推送全部」** 按钮
2. 系统按依赖顺序依次推送所有模块

## 状态说明

| 状态 | 说明 | 颜色 |
|------|------|------|
| 待处理 | 新导入数据，尚未校验 | 黄色 |
| 初检通过 | 单表校验通过 | 蓝色 |
| 初检错误 | 单表校验失败 | 红色 |
| 联检通过 | 外键引用校验通过 | 绿色 |
| 联检错误 | 外键引用校验失败 | 黄色 |
| 推送失败 | 同步正式表失败 | 黄色 |
| 已推送 | 成功同步到正式表 | 灰色 |

## 筛选与搜索

### 快速筛选
- **状态筛选**：选择待处理、校验通过、校验失败等
- **来源筛选**：选择 ERP、MES、PLM、Excel 等
- **关键词搜索**：输入关键词模糊匹配

### 精准筛选
1. 点击 **「精准筛选」** 按钮
2. 添加筛选条件：
   - 选择字段
   - 选择操作符（等于、包含、开头是等）
   - 输入值
3. 可添加多个条件
4. 点击 **「应用筛选」**

---

## 校验规则配置

点击 **「校验规则」** 按钮可查看当前模块的校验规则：

- **必填字段**：必须填写的字段
- **枚举字段**：只能选择特定值的字段
- **范围约束**：数值范围限制
- **外键约束**：引用其他表的数据
- **业务规则**：自定义业务校验规则

---

## 首页卡片说明

首页以卡片形式展示各模块：

- **待处理数量**：显示当前待校验的数据条数
- **异常数量**：显示校验失败的数据条数
- **红点角标**：有待处理或异常数据时，卡片右上角显示红色闪烁角标
- **点击卡片**：在新标签页打开模块页面

## 常见问题

### Q1: 导入数据提示"字段不存在"
**原因**：Excel列名与系统字段不匹配  
**解决**：检查列名是否与模板一致，或联系管理员配置字段映射

### Q2: 校验失败提示"外键引用不存在"
**原因**：引用的数据尚未导入  
**解决**：先导入被引用的主数据（如物料），再导入当前数据

### Q3: 推送失败
**原因**：正式表约束冲突或数据库异常  
**解决**：
1. 查看错误详情
2. 修正数据后重新推送
3. 或联系管理员检查正式表配置

### Q4: 数据重复如何处理
**建议**：
- 导入时选择「覆盖重复」策略
- 或使用「跳过重复」保留历史数据
- 避免使用「拒绝重复」导致批量失败
