# MyAPS API - 离线迁移 GUI 工具使用说明

## 概述

本工具是基于 Python tkinter 的可视化界面，提供以下功能：

| 标签页 | 功能 | 使用环境 |
|--------|------|----------|
| 1. 下载依赖包 | 在外网环境下载所有 Python 依赖 | 有外网 |
| 2. 安装依赖包 | 在内网环境安装离线依赖 | 无外网 |
| 3. 环境配置 | 可视化配置 .env 文件 | 内网 |
| 4. 服务管理 | 启动/停止服务、打开 API 文档 | 内网 |

## 快速开始

### 1. 启动 GUI

**Windows**:
```cmd
.offline_dev\gui\run_gui.bat
```

**Linux/macOS**:
```bash
bash .offline_dev/gui/run_gui.sh
```

**手动启动**:
```bash
python .offline_dev/gui/main.py
```

### 2. 外网机器 - 下载依赖包

1. 打开 GUI，切换到 **"1. 下载依赖包"** 标签页
2. 确认项目根目录正确
3. 选择 Python 版本（与内网目标机器一致！）
4. 选择目标平台（`win_amd64` = Windows 64位）
5. 点击 **"开始下载"** 按钮
6. 等待下载完成（底部日志实时输出）
7. 将整个 `myaps_api/` 目录打包传输到内网

### 3. 内网机器 - 安装依赖包

1. 将项目目录放到内网机器上
2. 打开 GUI，切换到 **"2. 安装依赖包"** 标签页
3. 确认离线包目录正确（`.offline_dev/packages/`）
4. 点击 **"开始安装"** 按钮
5. 等待安装完成

### 4. 配置环境变量

1. 切换到 **"3. 环境配置"** 标签页
2. 点击 **"从 .env.example 加载默认值"**
3. 修改数据库连接信息（内网地址）
4. 点击 **"保存到 .env"**

### 5. 启动服务

1. 切换到 **"4. 服务管理"** 标签页
2. 点击 **"启动服务"**
3. 点击 **"打开 API 文档"** 或手动访问 http://localhost:8000/docs

## 界面说明

### 1. 下载依赖包标签页

- **项目根目录**: myaps_api 文件夹路径
- **Python 版本**: 必须与内网目标机器一致（3.11 或 3.12）
- **目标平台**: 内网机器平台（`win_amd64` = Windows 64位）
- **输出目录**: 离线包保存位置

### 2. 安装依赖包标签页

- **项目根目录**: myaps_api 文件夹路径
- **离线包目录**: 存放下载好的离线包的文件夹
- **虚拟环境名称**: 虚拟环境名称（默认 `venv`）

### 3. 环境配置标签页

提供可视化的表单填写，包含：
- 应用配置（端口、地址）
- 项目配置（租户目录）
- MySQL 配置
- PostgreSQL 配置
- Redis 配置

### 4. 服务管理标签页

- **启动服务**: 启动 FastAPI 服务器
- **停止服务**: 停止运行中的服务器
- **打开 API 文档**: 自动在浏览器打开 API 文档
- **服务信息**: 实时显示服务状态和访问地址

## 日志输出

底部日志区域实时输出操作信息，不同颜色代表不同级别：

| 颜色 | 含义 |
|------|------|
| 蓝色 | 信息 (Info) |
| 绿色 | 成功 (Success) |
| 橙色 | 警告 (Warning) |
| 红色 | 错误 (Error) |

## 常见问题

### 1. GUI 无法启动

检查是否已安装 Python 3.11+，并添加到 PATH。

### 2. 下载依赖失败

- 确认网络连接正常
- 检查磁盘空间是否足够（建议 >2GB）
- 查看底部日志错误信息

### 3. 安装依赖失败

- 确认 .offline_dev/packages/ 目录完整
- 确认 Python 版本与下载时一致
- 某些包需要编译，可能需要安装 Visual Studio Build Tools

### 4. 服务无法启动

- 检查 .env 文件配置是否正确
- 检查数据库和 Redis 连接是否正常
- 检查 8000 端口是否被占用
- 查看 logs/ 目录下的日志文件

## 目录结构

```
.offline_dev/
├── gui/
│   ├── main.py          # GUI 主程序
│   ├── run_gui.bat      # Windows 启动脚本
│   ├── run_gui.sh       # Linux/macOS 启动脚本
│   └── __init__.py
├── packages/            # 离线包存放目录（下载后生成）
├── scripts/             # 命令行脚本
├── README.md            # 主迁移手册
└── GUI_README.md        # 本文档
```

## 技术说明

- 使用 Python 标准库 tkinter（无需额外依赖）
- 使用多线程处理耗时任务，避免界面卡死
- 支持跨平台（Windows/Linux/macOS）
- 与命令行脚本功能完全一致，只是可视化包装
